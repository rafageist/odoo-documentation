# Community Addons

## How to use this index
- Canonical addon notes live in module folders named after the technical module name.
- Category folders organize the catalog and should only contain index notes.
- Content is generated from `odoo19/addons` and then enriched by hand where analysis is needed.

## Relationship with core
- Jump back to `[[docs/Core/Core]]` when a module relies on ORM behavior, auth, reports, attachments, mail/threading, or other shared runtime services.
- Use the root note to decide whether a topic belongs to community, enterprise, or core before creating a new page.
