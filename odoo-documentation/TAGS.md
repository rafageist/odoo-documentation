# Taxonomía de Tags

- Versiones: `#v18`, `#v19`.
- Categorías: `#core`, `#community`, `#enterprise`.
- Dominio funcional (ejemplos): `#sales`, `#accounting`, `#inventory`, `#hr`, `#purchase`, `#website`, `#crm`, `#project`.
- Tipo de artefacto: `#module`, `#model`, `#view`, `#wizard`, `#controller`, `#report`, `#security`, `#data`.
- PlantUML: `#diagram`, `#sequence`, `#component`, `#class`.

Usa tags en `frontmatter` YAML:

```yaml
---
tags: [odoo, v18, core, module]
---
```
